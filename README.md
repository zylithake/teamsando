# How to make a blog post:
### If you get stuck at any point dm or ping me (@pitAngel) on discord

## Step 0:
you're going to want an editor for HTML. I use Notepad++(free) but you can use whatever works for you.

You will also need WinRAR/Something that can unzip .rar files. You do not need to pay for it.

## Step 1: 
Download blogpost_pack.rar above

## Step 2:
Unzip the blogpost_pack.rar. Inside the folder there should be 2 folders named "fonts" and "images" and an HTML file named "blogTemplate.html"

## Step 3:
Open "blogTemplate.html" in a web browser. You should see a blank blog page with our website background/fonts/images all loaded in just like the live one.

## Step 4:
### Writing the blog post:
I would recommend having all the text and images you want in the post already written/compiled before you begin so you can just copy/paste.

#### Title
There will be a comment with the text "REPLACE "TITLE" WITH BLOG TITLE" on line 92. The line immediately below that is where you will write your blog post title in place of "Title"

#### Content
There will be a comment with the text  "WRITE BLOG POST CONTENT HERE" followed by instructions ending on line 106. You can put your post content between the end of the instructions and the line that reads "DO NOT WRITE PAST HERE"

 ##### Text formatting
To make a section title, put the title between these tags  `<h2>  title  </h2>`
To make a paragraph break, type `<br>`

 #####T o insert an image:
-if it is hosted online
Insert it like this `<img src = "web-address-of-image.com">`

-if it is on your device
Put it into the same folder you have the blog post html file. Then insert it like this  `<img src = "your_File_Name.png">`
